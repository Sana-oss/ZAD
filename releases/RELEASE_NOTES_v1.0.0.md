# ZAD v1.0.0 — First Release

زاد — تطبيق إسلامي شامل ومجاني بالكامل، وقفًا لله تعالى.
ZAD — a comprehensive, 100% free Islamic app, endowed for the sake of Allah.

## ✨ Features / المزايا

- 🕌 **مواقيت الصلاة** — Prayer times calculated from your real device location, with Qibla direction
- 🔔 **تنبيهات الصلاة الأصلية (أندرويد)** — Native prayer notifications (Android) that work even when the app is completely closed and the screen is locked
- 📖 **القرآن الكريم** — Full Quran with progress tracking
- 📚 **الحديث الشريف** — Verified collection of prophetic traditions (Sahih al-Bukhari)
- 🕌 **الأذكار** — Morning & evening adhkar with counters and streaks
- 🧭 **اتجاه القبلة** — Qibla compass
- 🌙 **الوضع الليلي** — Dark mode
- 🌐 **PWA** — Installable web version for browsers (Android Chrome / iOS Safari)

## 📥 Installation (Android) / التثبيت على أندرويد

1. Download `ZAD-v1.0.0.apk` from the assets below / حمّل الملف من الأسفل
2. Open the downloaded file / افتح الملف الذي تم تنزيله
3. If Android asks for permission to install from this source, allow it / اسمح بالتثبيت من هذا المصدر إذا سُئلت
4. Install ZAD, then open it / ثبّت التطبيق ثم افتحه
5. Allow the **location** permission for accurate prayer times / اسمح بإذن الموقع
6. Allow the **notification** permission to enable prayer notifications / اسمح بإذن الإشعارات

## ℹ️ Notes

- The APK is signed with the official ZAD release key.
- The web/PWA version does **not** include native offline notifications; it is a browser-based experience.
- No personal data is collected. All preferences and counters are stored locally on your device.
- لا نقوم بجمع أي بيانات شخصية؛ جميع التفضيلات والعدادات محفوظة محليًا على جهازك.
